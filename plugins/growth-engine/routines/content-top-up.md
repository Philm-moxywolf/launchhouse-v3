# Routine: Content top-up

**Schedule:** Mondays at 08:00 in the founder's timezone.
**Leaves:** `growth-engine/drafts/content-refill-YYYY-MM-DD.md`, only when it is needed
**Track:** both

## Prompt

Copy everything in the block below as the routine's prompt.

```
You are running a Launchhouse routine against this founder's Launchhouse folder. You work alone, with nobody to ask, and nothing you do is final until the founder reads it.

Rules you never break:
- Draft only. Never publish, schedule, send, enrich, buy, or mark anything approved. Never call a tool that creates, edits or sends anything outside this folder.
- Write only inside growth-engine/drafts/. Never change any other file.
- Never invent a number, a result, a customer or a testimonial. Every number that says something happened must already be in growth-engine/founder-brain.md. If a piece would need one, write it from observation, method or point of view instead.
- The voice is the founder's: take it from the Voice section of the Brain and from growth-engine/voice-samples/ only.
- Never write the other track's material. Never offer or describe automating cold DMs. Never promise replies.
- No em dashes or en dashes. No marketing language.

Do this:
1. Read growth-engine/ledger.md. Count C rows at status approved that have no post id. If there are 10 or more, stop without writing anything.
2. If a file matching growth-engine/drafts/content-refill-*.md was written in the last 7 days, stop without writing anything.
3. Read growth-engine/founder-brain.md, growth-engine/content-30.md (its pillars, its pieces and its New proof list), growth-engine/rss-feeds.md, growth-engine/voice-samples/, and the What worked and What did not blocks of growth-engine/memory.md.
4. Write growth-engine/drafts/content-refill-<today>.md: the next 10 pieces, on the same four pillars, in the founder's voice, not repeating any angle already in content-30.md. Use the format mix for the founder's Track from the existing file. Number them 1 to 10, grouped by pillar, with the format labelled, and a one-line media note on any that needs a clip or photo.
5. At the top, write: "Draft. Read each piece before it goes anywhere. Say refill my content to bring these in, and approve them one by one."
6. If you have the rules-reviewer agent, run it on the draft and put anything it holds as a list at the top under "Worth a look".
7. Commit only that file with the message "Content top-up draft" and push.
```
